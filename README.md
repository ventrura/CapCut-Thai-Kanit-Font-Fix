# CapCut-Thai-Kanit-Font-Fix
แก้ไขปัญหาFontภาษาไทยใน Capcut ตัวเล็กกว่าปกติเมื่อเทียบกับภาษาอังกฤษ ใน UI ของ Capcut
วิธีใช้บน PC

ก๊อปไฟล์ zip ไปวางในเครื่อง แล้วแตกไฟล์ก่อน อย่ารันจากในไฟล์ zip ตรงๆ
ดับเบิลคลิก Fix-CapCut-Thai.bat
ถ้า CapCut เปิดอยู่ หน้าต่างจะถามว่าให้ปิดไหม ตอบ Y
ถ้าขึ้นคำว่า Fixed! ก็เปิด CapCut ใหม่ได้เลย

สิ่งที่สคริปต์ทำ

หาโฟลเดอร์ของ CapCut ทุกเวอร์ชันในเครื่องเอง ไม่ต้องรู้ว่าเครื่องนั้นเป็นเวอร์ชันไหน
สำรองฟอนต์เดิมไว้ก่อนทุกครั้ง แล้วใส่ฟอนต์ Kanit แทน
ถ้าเวอร์ชันไหนแก้ไปแล้ว จะข้ามไปเลย รันซ้ำได้ ไม่มีปัญหา

ข้อควรรู้

ถ้า Windows ขึ้นหน้าต่าง “Windows protected your PC” ให้กด More info แล้วกด Run anyway
พอ CapCut อัปเดตแล้วตัวหนังสือกลับมาเล็ก ให้ดับเบิลคลิก Fix-CapCut-Thai.bat ซ้ำ ใช้ได้เฉพาะ PC Windows OS ครับ
ถ้าอยากเอาฟอนต์เดิมของ CapCut กลับมา ให้ดับเบิลคลิก Restore-Original.bat
ถ้า CapCut รุ่นใหม่ๆ เปลี่ยนชื่อฟอนต์อีก สคริปต์นี้จะหาไฟล์ไม่เจอและขึ้นว่า “CapCut not found” ถ้าเจอแบบนี้อาจจะต้องลองวิธีอื่นครับ
